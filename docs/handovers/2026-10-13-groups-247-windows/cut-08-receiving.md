# Windows manual requester currency

Apply this separate five-path correction after the frozen Windows model consent
patch (75356660) and managed producer-origin custody patch (7bf1749a). The five
preimages are unchanged by those predecessors, but the new behavioral fixtures
use their real offer receipt helpers. Verify the manifest's exact preimages and
patch hash before applying; do not rebase the frozen images silently.

A durable System 2 source/model or agent-mode change previously returned from
its live commit tail without retiring the agent generation. A missing-model
modal could therefore authorize a pull for a requester withdrawn by that
setting, including a change away and back. The committed tail now retires the
original generation before logging, only for an actual changed source/mode.
No-op choices, refused writes and unrelated System 1 setting changes retain the
requester. Commit acknowledgement must be the exact integer true.

Screen disable already advances the existing Ollama auxiliary lifecycle, but
screenshots previously retained only their reading generation. A delayed
capture/read/answer failure arriving after disable and reenable could create a
fresh offer or notice. The trigger now captures the original auxiliary epoch
before readiness/native/target getters, then retains a bound generation/epoch
currency callback. Capture, HTTP dispatch, answer continuation, modal consent,
notices and surface publication reuse that callback. It checks current
prediction enablement and suspension, and refuses after any lifecycle ABA.
The legacy one-argument screenshot render guard now refuses because it supplies
no original epoch; its original stale-guard assertion is retained.

Agent actions remain independent of the prediction enablement switch. The
change adds no global guard to direct downloads or automatic model notices.
Optional requester predicates on shared vision transports default to the
existing unscoped caller contract, so agent and translation transport callers
are preserved. There is no server start/stop, external-server ownership change,
readiness grant, qualification flip, native API or DLL modification.
