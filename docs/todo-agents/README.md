# Agent handoff files

One file per piece of work in flight, written by the agent that does it (linked from
[the checklist](../ERGOPTIPLUS_TODO.md)). Each file states what is done (commits), what
remains, the exact next command, the risks and the checks only a real machine can do. Delete a file
when its work is finished and its durable lessons are in [docs/memory](../memory/README.md).
