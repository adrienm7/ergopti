# Linux field report coverage

The "To confirm on Linux" lines of `TODO-tests-linux.md` ask for things only a real Linux
desktop shows. One run of `bash tools/dev/collect-linux-field-report.sh`
answers every open line: each line carries a `<!-- field-point: <id> -->` tag,
`static/ergopti_plus/linux/diagnostics/data/field_todo_coverage.json` names the evidence
that decides it, and the report ends with `todo_summary.md` (and
`todo_summary.json`): one verdict per point. There is no mode to choose: the
report always runs the daemon's field run, the probes and the guided steps
(decided by the coordinator on 2026-11-11, to review by the maintainer).

The verdicts are the macOS report's
([macos-field-report-coverage.md](macos-field-report-coverage.md#verdicts)).

## Probe and guided steps

The collector runs them itself, after the daemon's field run, with
`tools/dev/field-guided.py` and
`static/ergopti_plus/linux/diagnostics/data/field_guided_steps.json`; each writes
`field_guided/NN_<step>.json` in the field run's result shape.

- A probe step reads the session once with no person: `/dev/uinput` writable,
  an evdev node readable, the `ergopti-hotstrings.service` user unit enabled, a
  polkit agent running, the compositor focus reporter's « Listening for … focus
  reports » line in today's log.
- An observed step prints its gesture (`👉 GUIDED <step> (up to <n> s): …`),
  reads its counts before and every few seconds after, and passes once each
  rose: `events_window_topo` and `events_network` rows by kind in the Metrics
  database (read-only, lock-free), or matching lines of today's day log (the
  prediction cancellations). A count meant to stay steady that rose
  (`vpn_connected` while no tunnel came up) fails it. Type `s` and Enter to skip.
- An attested step is what only a person sees: type `y`, `n` or `s` then Enter.

The raw day log is read on the machine to count lines, never copied; only
counts and closed codes reach the report.

## Windows

The Windows counterpart is not built here: « To confirm on the Windows PC »
keeps its live checks (`docs/tooling/windows-maintainer-checks.md`). Its
follow-up is the same three pieces: field-point tags, collector-side guided
steps (`tools/dev/field-guided.py` reads a declaration and counts, so a
PowerShell collector can call it), and `field-todo-summary.py --os windows`.
