## Branch-history recovery

Owned historical branches with commits outside current Dev are preserved as an
inert Git bundle, alongside exact original names and tip identities. This keeps
unqualified historical variants recoverable without merging their old runtime
changes into the product. Bundle verification and restoration receipts identify
the exact prerequisite Dev commit. Fetch the full Dev history before verifying
or restoring the bundle. Restored refs are recovery data, not approved branches.

`payload-manifest.json` records every retained file's size and SHA-256. The
branch retirement plan records exact original names and custody checks. Actual
deletions and exclusions are confirmed by the final coordination comment in
repository issue #86 after publication. Ownership is never inferred from a
macOS-looking branch name alone. No direct Main push or
release is part of this retirement.
