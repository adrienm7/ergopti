## Prepared correction

The optional native conditional publisher returns its private third cleanup
capability on a refusal after publication or refused release. It retains the
exact canonical writer owner and, where applicable, this operation's private
staging cleanup identity. Its callback performs cleanup only and returns literal
settlement/effect flags. Repeated settled callbacks cannot unlock another owner,
unlink a live source, or repeat publication. The ordinary two-argument FileSystem
port remains unchanged; the shared exact writer forwards the identical closure.

Shared exact file inverse logic retains forward and inverse publication debt,
verifies an already-published inverse target without republishing, preserves
external successors, and settles native forward cleanup before runtime rollback.
Generic transaction and secondary-file backups retain release-only debt and
preserve backup data. Mac Hotstrings calls its secondary inverse even when a
failed publication never reached source adoption; secondary compensation remains
pending after its cleanup function has settled until its exact source returns.

Failed layer imports propagate a private failed record through LayerPreset and
NavLayer into ScopeLayer. No successful public capability is issued. Native
release debt cannot be bypassed by the no-record, absence, or no-effect shortcuts.
An explicitly acknowledged no-effect refusal preserves later foreign content.
The parent's failed inverse restoration also retains native publication debt and
verifies its target without overwriting foreign bytes or repeating publication.
