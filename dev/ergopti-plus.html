Les fautes les plus fréquentes, balayées à la frappe

Apostrophes typographiques, capitalisation des marques, accents oubliés. Ce n’est pas un correcteur après coup : c’est appliqué pendant que vous tapez.

Touche magique ★

Un suffixe explicite pour les expansions longues

Pour vos snippets fréquents — formules, signatures, identifiants — la touche ★ déclenche l’expansion sans aucune ambiguïté. Aucun risque de collision avec la frappe normale.

  • ct★ → c’était
    ct★ génial → c’était génial
  • pex★ → par exemple
    pex★ ce matin → par exemple ce matin
  • pcq★ → parce que
    pcq★ il pleut → parce qu’il pleut
  • eef★ → en effet
    eef★, c’est vrai → en effet, c’est vrai

1 Répéteur de lettre

Si aucune abréviation ne correspond, ★ double simplement la lettre précédente. Plus aucun SFB sur les doublons.

  • l★ → ll elle
  • r★ → rr erreur
  • t★ → tt attendre
  • n★ → nn année

2 Déclencheur d’abréviations

Si les lettres précédentes forment un trigger connu, ★ expanse à la place. Les deux modes sont décidés au moment de la frappe — sans configuration.

  • a★ → ainsi
  • c★ → c’est
  • dé★ → déjà
  • ê★ → être
  • m★ → mais
  • pê★ → peut-être

Hotstrings dynamiques

Certaines valeurs changent tous les jours (la date) ou ne doivent pas être écrites en dur (téléphone, IBAN). Le préfixe @ les calcule au moment précis du déclenchement, depuis l’éditeur d’informations personnelles.

  • dt★ → 10/11/2026 Date du jour
  • date★ → 10 novembre 2026 Date en lettres
  • @ph → +33 6 12 34 56 78 Téléphone configuré
  • @np★ → Moyaux ⇥ Adrien Remplissage de formulaire

Nom, e-mail, téléphone, adresse, IBAN : tout est centralisé dans une seule fenêtre — les hotstrings dynamiques s’en servent automatiquement.

3 Choisissez (ou écrivez) votre profil de prompt

○○○ Autocomplétion — Aucun prompt, juste le contexte

Aucune instruction injectée : le modèle reçoit le contexte brut et continue. Idéal pour le code et les formats stricts.

●○○ Basique — Prédiction simple

Instruction minimale : continuer le texte entre N et M mots, sans commentaire. Le compromis vitesse/qualité par défaut.

●●○ Avancé — Correction + Prédiction

Deux lignes en sortie : la fin de phrase corrigée, puis la suite prédite. Bilingue FR/EN, avec exemples intégrés pour les petits modèles.

●●● Batch Avancé — 1 req. avancée avec {n} prédiction{s} batch

Le contrat « Avancé », mais N suggestions distinctes en une seule requête — beaucoup plus économique que N appels.

Tap-Holds

Sept touches à double vie.

Un appui bref déclenche une action, un maintien conserve le rôle de modificateur. La même logique sur les deux OS : les mêmes doigts déclenchent les mêmes gestes, avec le modificateur natif de chaque plateforme — Ctrl sur Windows, ⌘ sur macOS. L’objectif : une expérience unifiée, quel que soit l’ordinateur devant vous. Ce sont les défauts livrés ; chaque touche, action et délai se change depuis le menu.

CapsLock

Raccourcis

Des actions qui règlent de vraies galères.

Bien au-delà du copier-coller : voici quelques-unes des actions les plus utiles — chacune assignable à n’importe quelle touche, tap-hold ou geste.

🖱

Téléporter la souris

Le curseur saute sur l’écran voisin d’un seul tap — fini de deviner vers quel bord le pousser pour changer de moniteur.

🔦

Surbrillance du curseur

Perdu votre souris sur trois écrans ? Un halo la fait ressortir à l’instant — parfait aussi en présentation.

📸

Capture en un tap

Région, fenêtre, plein écran ou OCR — sur la touche à gauche du 1, sans chercher le raccourci système.

☰

Sélectionner la ligne

La ligne entière sélectionnée d’un geste, sans viser au pixel ni tripler-cliquer.

🌐

Ouvrir lien ou chemin

Ouvre l’URL ou le chemin de fichier local sous le curseur — où qu’il se trouve dans le texte.

AA

Changer la casse

Bascule la sélection en MAJUSCULES, minuscules ou Casse De Titre — plus besoin de retaper.

Roulements de bigrammes

Des séquences inconfortables remplacées par des roulements fluides sur doigts adjacents. Vous tapez ce qui est confortable, le mot correct sort.

  • sx → sk ask, task, desk
  • cx → ck back, check
  • hc → wh what, when, while
  • nt’ → n’t don’t, can’t

Réduction des SFBs

La virgule devient une super touche morte qui neutralise les derniers bigrammes à même doigt. Les touches É/È/Ê s’en chargent côté gauche.

  • ,t → pt aptement
  • éà → ié ciel
  • àé → éi antérieur
  • êe → œ sœur

Symboles de programmation

Les combinaisons pénibles du code deviennent des roulements vers l’intérieur sur la home-row d’Ergopti.

  • $= → => fat arrow
  • +? → -> Rust, types
  • !# → != différent
  • <@ → </ fermeture HTML

, + voyelle = J

Le j cède sa place à la touche ★. La séquence ,+voyelle — inexistante en français — produit le j : ,a → ja, ,e → je.

, + consonne = lettres rares

,è → z, ,y → k, ,s → q, ,c → ç. Les lettres rares restent à une frappe du repos.

Q + voyelle = QU

En français, q implique presque toujours u : tapez qe, qoi — le u s’insère tout seul.

ê = circonflexe direct

Une touche dédiée pour le cas le plus fréquent, et êa, êi, êo, êu pour â, î, ô, û.

Suffixes en à

às → ement, àt → ation, àr → eur… Les terminaisons fréquentes en deux frappes au lieu de cinq.

Apostrophe typographique

Dans du texte, ' produit ’ ; dans du code, elle reste droite. Aucun réglage.

Questions fréquentes

Tout ce qu’on se demande avant d’installer.

Confidentialité, performance, compatibilité — les réponses courtes, sans détour.

Est-ce que quelque chose part sur Internet ?

Non. Tout — hotstrings, prédictions IA, métriques — est calculé et stocké sur votre machine. Les modèles d’IA tournent en local ; si vous branchez une clé d’API distante (optionnel), elle est chiffrée dans le Trousseau macOS ou via DPAPI sur Windows, et vous choisissez explicitement quand l’utiliser.

Est-ce que ça ralentit ma frappe ?

Non perceptiblement. Les expansions sont synchrones et instantanées ; les prédictions IA sont asynchrones et n’interrompent jamais la frappe — une suggestion s’affiche quand elle est prête, et vous l’ignorez ou l’acceptez d’une touche.

Quelle différence entre Ergopti et Ergopti+ ?

Ergopti est la disposition clavier — l’agencement des lettres. Ergopti+ est le logiciel compagnon : hotstrings, IA, tap-holds, gestes, métriques, qui fonctionne sur n’importe quelle disposition. Utilisez l’un sans l’autre, ou les deux ensemble pour le gain maximal.

Ça marche dans toutes mes applications ?

Oui, le driver agit au niveau du système : navigateur, éditeur de code, messagerie, traitement de texte… Les champs de mot de passe sont volontairement ignorés. Quelques applications très verrouillées (certains jeux anti-triche) peuvent bloquer l’injection de touches.

Faut-il utiliser la disposition Ergopti ?

Non. Tout fonctionne sur n’importe quelle disposition (AZERTY, QWERTY, Bépo…). La disposition Ergopti débloque des bonus supplémentaires (roulements, super-touches), mais elle est totalement optionnelle.

C’est vraiment gratuit ?

Oui : gratuit, open-source, sans compte et sans télémétrie. Le code est auditable publiquement sur GitHub.

Comment on désinstalle ?

Chaque fonctionnalité se désactive d’un clic dans le menu, et l’application se retire comme n’importe quelle autre. Vos données (base SQLite locale) vous appartiennent et partent avec.

Windows, macOS ou Linux ?

Windows, macOS et Linux partagent de nombreuses fonctionnalités. Leur disponibilité, leurs conditions et certains comportements diffèrent selon le système : consultez les inventaires ci-dessous et l’audit de parité du dépôt. Le pilote Linux reste en alpha.

  • Ergopti sans installation. Le driver peut émuler la disposition Ergopti par-dessus votre layout actuel — aucun installateur, aucun droit admin. Idéal au bureau ou sur un poste verrouillé.

  • Moteur de gestes intégral. 36 emplacements de gestes trackpad et 3 axes continus, là où Windows en propose 10.

Applications macOS incluses

Des utilitaires signés Ergopti, livrés directement dans le driver macOS — rien de plus à installer.

App Cloner

Clonez n'importe quelle application (VS Code, Slack…) : le clone reçoit sa propre icône teintée, son nom et son profil isolé. Plusieurs instances vraiment séparées, sans droits admin.

Encryptor

Déposez un fichier sur l'icône : il est chiffré en AES-256 (extension .enc). Redéposez-le : il est déchiffré. Aucun réglage, rien à apprendre.
