## How to read the provenance

- **explicit_policy**: Rationale explicitly documented in source/tests/maintainer decisions.
- **platform_constraint**: Native API, runtime, hardware or installation prerequisite; not universal OS impossibility unless established.
- **guarded_unimplemented**: Deliberately safe refusal around an unfinished capability; NOT a product decision to omit it.
- **observed_not_decided**: Behavior is evidenced but product intent or desired cross-OS equivalence is not established.
- **shared_policy**: Current implementations share the policy; an older OS-specific claim was refuted.

The machine-readable companion is [intentional-differences.json](intentional-differences.json). It is an audit snapshot, not a second runtime configuration source. Each module report retains additional native conditions, decisions, hypotheses and refutations.
