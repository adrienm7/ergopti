| Classification            | Meaning                                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------- |
| explicit_policy           | An explicit declaration or settled product decision, including declared host-only capability.           |
| explicit_mechanism        | Different native owners implement equivalent product intent.                                            |
| implementation_constraint | An identified OS/dependency/API constraint; no universal technical impossibility is inferred beyond it. |
| observed_defect           | Confirmed actionable behavior within the report’s explicit executed/source-derived evidence boundary.   |
| observed_limit            | Measured or source-reviewed limit, coverage gap, or weaker evidence that is not a new confirmed defect. |
| unknown_intent            | Difference observed, but the product/privacy obligation needed to call it a defect is unestablished.    |
