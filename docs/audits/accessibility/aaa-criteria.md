# WCAG 2.2 AAA: what is measured and how the rest is checked

Written on 2026-11-24 (Paris time) for the TODO item « AAA measured in CI, red
below perfect » (maintainer, 2026-11-23: WCAG 2.2 AAA on the site, Ergopti
Studio, Ergopti+ and every app window). This file lists every AAA success
criterion of WCAG 2.2, the gate that measures it when one can, and the check
that replaces a measure when no tool can make one. Results and history stay in
[the audit](README.md).

## The ratchet

Both browser gates count every axe violation per page (or window), scheme,
frame (or state) and rule, and compare the counts with the baseline committed
beside them (`site-accessibility-baseline.json`,
`app-windows-accessibility-baseline.json`). A new row or a higher count fails
CI; a lower count asks for `--update-baseline`, so the baseline can only fall.
HTML_CodeSniffer's errors are counted the same way, per page (or window),
scheme, frame (or state) and code, in a ratchet of their own
(`site-htmlcs-baseline.json`, `app-windows-htmlcs-baseline.json`, each rule
written `htmlcs:<code>`). HTML_CodeSniffer 2.5.1 reads only `rgb()` and hex
colours and no alpha below 1: the scan hands it the browser's conversion of
`color(srgb …)` and `oklab(…)` and composites a translucent colour over what
is behind it (fifteenth pass). A contrast it still cannot compute (a layer
over an image or a gradient, SVG text over its shapes) is counted under its
code suffixed `.Unmeasured`, still gated, so that a measured ratio below 7:1
keeps a row of its own. An error on an element the page does not render is
listed in the report only; the state that shows it is scanned.
The target is an empty baseline. The last `color-contrast-enhanced` rows went
on 2026-11-24 (thirteenth pass); the rows left are the 44 px targets of 2.5.5,
which the gates measure themselves (`target-size-enhanced`, below).

## Every AAA criterion of WCAG 2.2

« Measured » names the gate that fails on a regression. « Partly » means a gate
measures a share of the criterion and the rest is checked by hand. « Manual »
means no tool can decide it; the check is then a review, recorded in the audit,
or a rule the gates hold the code to.

| Criterion                                      | Status   | How it is checked                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.2.6 Sign language (prerecorded)              | Manual   | The site holds no prerecorded video with speech: the demos are silent screen recordings of typing (seventh pass, « Images and media »). Any new video with speech needs a sign language version (LSF) before it ships; reviewed at each new media in the audit.                                                                                                                                                                                                                                                                                |
| 1.2.7 Extended audio description (prerecorded) | Manual   | Same scope: no synchronised media with speech. A new one is reviewed for pauses the description needs.                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 1.2.8 Media alternative (prerecorded)          | Manual   | Each silent demo has its text alternative beside it (seventh pass); a new media gets a full text version, reviewed in the audit.                                                                                                                                                                                                                                                                                                                                                                                                               |
| 1.2.9 Audio-only (live)                        | Manual   | Not applicable: no live audio anywhere. Stated in the audit; reviewed if live media is ever added.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 1.3.6 Identify purpose                         | Manual   | Needs a person to judge which regions, controls and icons carry a common purpose. Checked in the manual audit: landmarks named (the outline gate, `heading-landmarks.cjs`, measures their presence), `autocomplete` on personal fields, icon buttons named.                                                                                                                                                                                                                                                                                    |
| 1.4.6 Contrast (enhanced)                      | Measured | axe `color-contrast-enhanced` and HTML_CodeSniffer's `1_4_6.G17` and `G18` in both gates, light and dark; the shared text tokens are also held to 7:1 without a browser by `tools/test/test-app-colour-contrast.cjs` (section 7). Text over images and gradients axe cannot compute is reviewed by hand.                                                                                                                                                                                                                                       |
| 1.4.7 Low or no background audio               | Manual   | Not applicable: no audio. Reviewed if audio is added.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 1.4.8 Visual presentation                      | Partly   | `site-reading.cjs` measures no justified text, lines of 80 characters at most, and no clipping at 200 % text with wide spacing, on every page and Studio frame. The settings dialog offers the reader's own font, spacing and colours; `test-site-accessibility-ratchet.cjs` checks its preferences. Paragraph spacing and width choice in the app windows: manual audit.                                                                                                                                                                      |
| 1.4.9 Images of text (no exception)            | Manual   | A person judges whether an image holds text (logos are allowed). Each image is reviewed in the manual audit; `page-images.cjs` lists them.                                                                                                                                                                                                                                                                                                                                                                                                     |
| 2.1.3 Keyboard (no exception)                  | Partly   | The keyboard operability gates (`keyboard-operability.playwright.cjs`, `lib/app-window-checks.cjs`) fail on anything a mouse can use and the keyboard cannot reach. Drawing-only paths (path-dependent input) and native windows: manual keyboard walk per window.                                                                                                                                                                                                                                                                             |
| 2.2.3 No timing                                | Manual   | That no flow sets a time limit (downloads and updates wait for the user): manual audit, for each new flow.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 2.2.4 Interruptions                            | Partly   | axe `meta-refresh-no-exceptions` refuses an automatic refresh. Notifications, tooltips and update prompts that interrupt are reviewed in the manual audit (each can be postponed or turned off in the menus).                                                                                                                                                                                                                                                                                                                                  |
| 2.2.5 Re-authenticating                        | Manual   | Not applicable: no sign-in. Reviewed if one is added.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 2.2.6 Timeouts                                 | Manual   | Not applicable: no data is lost to inactivity. Reviewed with 2.2.3.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 2.3.2 Three flashes                            | Manual   | No tool in the stack measures flashes. Reviewed by watching each animation; no animation flashes, and reduced motion stops them (2.3.3).                                                                                                                                                                                                                                                                                                                                                                                                       |
| 2.3.3 Animation from interactions              | Partly   | The site gate scans with reduced motion emulated and checks the hero demo's pause control. That each animation triggered by an interaction can be turned off, on the site and in the app windows: manual audit.                                                                                                                                                                                                                                                                                                                                |
| 2.4.8 Location                                 | Manual   | A person judges whether the reader knows where they are (current page in the navigation, current Studio tab, window title). Reviewed in the manual audit.                                                                                                                                                                                                                                                                                                                                                                                      |
| 2.4.9 Link purpose (link only)                 | Partly   | axe `identical-links-same-purpose` flags same-named links to different places. Whether each link's own text says where it goes is read by hand in the manual audit.                                                                                                                                                                                                                                                                                                                                                                            |
| 2.4.10 Section headings                        | Partly   | The outline checks (`heading-landmarks.cjs`) fail on a skipped heading level, no h1 or an unnamed landmark. Whether each section has a heading is judged in the manual audit.                                                                                                                                                                                                                                                                                                                                                                  |
| 2.4.12 Focus not obscured (enhanced)           | Partly   | The reading gate fails when an element sits under the sticky header. The keyboard walks check each stop has a focus indicator; whether any part of the focused element is hidden by a popover or a sticky bar is checked during the manual keyboard walk.                                                                                                                                                                                                                                                                                      |
| 2.4.13 Focus appearance                        | Partly   | The walks fail on a stop without a focus indicator of its own; the shared ring is 2 px of the accent (`theme.css`, 7:1 or more on the surfaces since 2026-11-24). Its area and 3:1 change of contrast per state are not measured: manual audit.                                                                                                                                                                                                                                                                                                |
| 2.5.5 Target size (enhanced)                   | Partly   | Measured by both gates themselves (`tools/test/lib/target-size.cjs`, rule `target-size-enhanced` in their ratchets), since axe's `target-size` stops at the AA 24 px of 2.5.8: every visible, enabled control is at least 44 by 44 CSS px, a link in a sentence, a field with its labels and an unstyled range or colour field excepted, counted once per kind of target (tag, classes, role and type) so that a page drawing one more row of data does not move the count. The « essential » exception is judged by hand in the manual audit. |
| 2.5.6 Concurrent input mechanisms              | Manual   | No page restricts the input to one kind (touch, mouse, keyboard, pen). Reviewed in the manual audit on a touch screen.                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 3.1.3 Unusual words                            | Manual   | A person judges which words are jargon: the layout and typing terms are explained in the site's pages and the help text (eleventh pass). Reviewed with each new page.                                                                                                                                                                                                                                                                                                                                                                          |
| 3.1.4 Abbreviations                            | Manual   | Same review: an abbreviation is spelled out at first use or in its tooltip (SFB, LLM, AZERTY…).                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 3.1.5 Reading level                            | Partly   | No tool rates French reading level reliably. The reading gate fails on a sentence of 30 words or more in a page's running text (`long-sentence`); the rest is a plain-language review (seventh and eleventh passes).                                                                                                                                                                                                                                                                                                                           |
| 3.1.6 Pronunciation                            | Manual   | Reviewed by hand: a word whose meaning depends on how it is said needs its pronunciation beside it.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 3.2.5 Change on request                        | Partly   | axe `meta-refresh-no-exceptions` refuses a timed redirect. That pop-ups, new windows and focus moves happen only on request, and that a link opening a new window says so: manual audit.                                                                                                                                                                                                                                                                                                                                                       |
| 3.3.5 Help                                     | Manual   | Context help per form: the typing dashboard's was reviewed in the eleventh pass; the other forms in the manual audit.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 3.3.6 Error prevention (all)                   | Manual   | A person checks that each submission can be reversed, checked or confirmed (the Studio's undo is tested by the site gate). Reviewed per form in the manual audit.                                                                                                                                                                                                                                                                                                                                                                              |
| 3.3.9 Accessible authentication (enhanced)     | Manual   | Not applicable: no sign-in. The token prompt must accept a pasted token; reviewed in the manual audit.                                                                                                                                                                                                                                                                                                                                                                                                                                         |

The native windows (menus, dialogs and tooltips drawn by AutoHotkey,
Hammerspoon and the Linux driver) have no automated AAA measure at all: they
are part of the manual audit item of TODO.md, criterion by criterion as above.
