no real-time sleep or native desktop latency is measured. The Linux program runs

Root independently opens and replays these programs. The four source notes and

transient-repeat timing was found. The shared declaration describes portable
repeat but specifies no repeat-specific delay. The pure repeat corpus has no
timestamps. Historical memory calling Windows repeat "ungated" is descriptive
precedent, not an OS-exception policy. macOS's explicit-star bypass has a local
source rationale; it does not settle all cross-OS timing choices.
