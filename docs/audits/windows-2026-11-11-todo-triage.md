# Windows TODO triage after the PC suite run, 11 November 2026

Every open Windows or AutoHotkey item of `TODO.md` in scope (Windows CI reliability, the Windows lines of the
cross-platform feature inventory, the [PHYS-W] lines, Native acceptance, the Windows parts of « Slowness, every
driver » and « One configuration layout on every OS », Before publishing, the whole « To confirm on the Windows
PC » section and « Remaining code work > Windows ») is classified against the evidence of 10 and 11 November.

## Evidence

- The whole AHK suite ran natively on the maintainer's PC: the 14 module groups of `TEST_MODULE_GROUPS`
  (`static/ergopti_plus/windows/tests/test_framework.ahk`), 20,286 tests. Its only reds were token-exchange budget
  (2), shortcut path case (1), TakeNote (2), Kana one-shot (2), layout-row (7) and symlink (2). All are fixed or
  now report NOT EXECUTED with their reason (bb49219540, da5daad768), except TakeNote different-folder, which
  `TODO.md` keeps.
- `e2e/run_e2e.ahk` ran 90/90.
- `--reverse` on the `llm` group passes 2295/2295 after the order fixes.
- `tools/maintainer/windows-live-checks.cjs` ran 21 pass and 7 fail, with fixes in progress. No item is closed on
  a live check, because which checks failed is not recorded here.

A test named by an item counts only for that item's automated part. Each one was checked with `git ls-files`, and
its group was read from `TEST_MODULE_GROUPS`. Line numbers are those of `TODO.md` after this triage's edit.

## Classes

- **A**: closed by the evidence above. « A part » means the automated part is closed and `TODO.md` carries a
  « PC run 2026-11-11 » line under the item. The class then names what remains.
- **B**: automatable now by a code change, with its files and its size (S, M or L).
- **C**: needs a person, real hardware, an account, a second Windows account, a corporate network or a maintainer
  decision.
- **D**: blocked by something the item names.
