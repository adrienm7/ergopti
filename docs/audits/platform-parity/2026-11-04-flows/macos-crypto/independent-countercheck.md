## Limits and final disposition

No candidate was refuted under its narrowed mechanism. MCR-001 must retain its explicit approved-overwrite premise and distinguish proposed atomic failure contract from an existing documented promise. MCR-002/MCR-004 prove secret argument transport, not universal process visibility or measured Mac exploitation. MCR-005 is the strongest transactional mismatch: actual prior reference survives while its mutable referent changes. MCR-006 is actual acquisition ACK loss, not stale callback after cancelled timer.

CBC corruption with successful primitive exit remains an evidenced **unauthenticated-format limitation**. No authentication promise was established, so it is correctly absent from confirmed findings. Distinct intentional policies (hardware-derived key, field-selective encryption, natural mutation settlement, HF SDK file persistence, proxy plaintext and unavailable PC Encryptor) must remain explicit rather than converted into new defects.

Compiled AppleScript delivery, native Mac process inspection, Security.framework permission/locking, real token SDK/network, native timers and real DB migration remain unexecuted. This countercheck neither certifies those boundaries nor inflates fixture success into native feature readiness.
