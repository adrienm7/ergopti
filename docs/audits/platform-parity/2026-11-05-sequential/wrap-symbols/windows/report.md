## WSW-001 — Saved custom pair is ignored by remapped wrap keys

Severity **medium**, confidence **high**; G2, plus configured-delimiter consistency. Source owners: `windows/ui/menu/menu_shortcuts.ahk` `_WS_MenuAddCustom`, `windows/infra/wrap_symbols_config.ahk` AddCustom/BuildActivePairs, `windows/modules/keymap/layout.ahk` roll registration/HashtagOrQuote/WrapTextIfSelected; generated-layout action construction in `modules/keymap/layout/layout_ergopti.ahk` has the same bound-delimiter mechanism.

Reachable source-projected reproduction:

1. Enable the wrap-selection feature, keep built-in `#` enabled and the Ergopti/Ergopti+ hashtag_quote roll enabled.
2. In Shortcuts -> wrap symbols -> Add custom, enter opening `#`, then closing `~`. Both dialogs accept these one-character inputs; there is no collision/duplicate prohibition. The normal commit persists the pair and publishes `_WS_ACTIVE_PAIRS["#"] = {left="#",right="~"}`. The custom submenu shows checked `# … ~`.
3. In a supported UIA editor, select `alpha`; allow a current complete selection snapshot; ensure the preceding output is neither `(` nor `[` so the quote-roll shortcut does not apply. Press real AltGr+SC017, without layer Shift.
4. Actual registered route is `Hotkey("SC138 & SC017", _RollHashtagQuoteHandler, "I2")` -> `_RollHashtagQuoteEmit` -> `HashtagOrQuote` -> `WrapTextIfSelected("#", "#", "#")` -> `SendInstant("#alpha#")`. The saved pair predicts `#alpha~`.

Root: the remapped route consults `WrapSymbols_IsEnabled(LeftSymbol)` but never reads current `_WS_ACTIVE_PAIRS` or the custom pair. Left/right arguments come from the built-in layout descriptor or hardcoded roll caller. On successful wrapping SendInstant emits its final low-level SendInput burst, so the prefix watcher does not reinterpret that successful paste through the current active custom pair. No error is raised; the wrong pair is a successful output. Persistence is not the failure: RAM and file agree on the custom choice and the OS-layout prefix route reads it correctly.

Healthy/refused controls: without the custom override this same remap correctly produces `#alpha#`; with a standard pass-through OS layout the prefix route snapshots active pairs and passes the current `#…~` Pair to `_PrefixTryWrapSelection`. A refused custom write leaves the previous runtime map and menu projection untouched. Disabling the built-in left currently suppresses the remap even if a same-left custom remains enabled; preserve existing intentional built-in disable behavior while defining custom precedence consistently.

Existing `test_wrap_symbols_gate.ahk` expressly documents that this remapped route is separate, but asserts only that `WrapSymbols_IsEnabled` appears; it does not test current custom delimiters. `test_wrap_symbols_global_transaction.ahk` covers real persistence and menu labels, without crossjoining the committed pair to a remapped output.

Regression direction: genuine AHK safe-port fixture should drive the actual two-dialog `_WS_MenuAddCustom` owner through acknowledged private persistence, then invoke the actual registered remap chain with a faithful current selection seam and recording final sender. Compare no override/custom left/right collision/remove/reload/disabled/refused-save controls and both opening/closing symbols across OS-layout prefix and Ergopti remap routes. Do not stub AddCustom's commit owner into an answer or merely inspect a label. Native app receiving remains a separate qualification.

Decisive retained evidence: `proofs/source-contract.mjs`, `proofs/source-contract.log` WSW-001; all source projection.

## WSW-002 — Bounded UIA selection is pasted as if it were complete

Severity **high**, confidence **high**; G2, plus selected-text integrity. Source owners: `windows/adapters/uia_worker.ahk` request handler and `UIASW_MAX_TEXT_CHARS`, `windows/modules/keymap/uia_selection_worker.ahk` request/payload/snapshot consumer, `windows/modules/keymap/layout.ahk` selection publication/consumption/WrapTextIfSelected; `windows/vendor/UIA.ahk` actual COM GetText facade.

Reachable source-projected reproduction: in a UIA TextPattern-capable editor other than excluded Code.exe, select a string of 8192 ASCII `a` characters followed by tail marker `Z` (8193 characters). Enable wrap-selection with default `#…#`; let the idle-gated worker return while the same HWND/control/input generation remains current and consume its cache within 750 ms. Invoke the concrete AltGr+SC017 remap chain above with no quote-roll context. The selection request always passes 8192. `Ranges[1].GetText(MaxTextChars)` returns only the first 8192 characters under the native maximum-length contract; it cannot include `Z`. The handler marks any nonempty non-newline-only Body `ok`, with no truncation/completeness flag. The parent cache publishes that Body unchanged. `GetUIASelection` validates only context/age/one-time ownership and returns the truncated Text. `WrapTextIfSelected` submits `#` + that prefix + `#` as a replacement for the entire still-selected 8193-character range, dropping `Z`. The pass-through prefix route similarly reconstructs only the bounded prefix after its already-visible symbol replaced the original range.

This does not require a stale callback, clipboard refusal, provider timeout or focus change. Keep every such control healthy and stable. The failure is a bounded successful read misclassified as a complete selection. At or below the limit a complete range can wrap correctly; the smallest over-limit ASCII range exposes the missing completeness distinction. Large Unicode/newline selections compound the integrity concern but are not needed for the repro. No native output size/loss was measured here.

Root: a safety/performance ceiling on GetText is reused as full-selection content, while the output action replaces the complete native selection. The real vendor facade passes maxLength directly to `IUIAutomationTextRange.GetText` via COM; it does not add a full read. No later owner compares captured text/range length, queries range end, reports truncation or refuses exactly-at-limit captures. The wire payload has only status/HWND/control/Text, and its accepted status vocabulary contains no truncated result. Normal successful `ok` publication logs no warning; the existing timeout/stale/failed backstops do not run. Native paste success would not recover the missing suffix.

Regression direction: keep the bounded worker process, deadline and input/context fences. Add a bounded completeness decision (e.g. capped lookahead or bounded endpoint check), and refuse wrapping an incomplete selection with an explicit diagnostic. Do not remove the cap or read an unbounded document. A genuine AHK worker fixture with a faithful TextPattern range must cover empty/8191/8192/8193/large selections, surrogate and CRLF boundaries, current/stale/canceled/deadline controls; pass actual worker result through parent publication, single-use consumer and public wrapper, then verify output preserves every selected character or refuses. The native editor receiving must confirm whole-range replacement and undo separately.

`test_uia_selection_background_poll.ahk` requires `GetText(MaxTextChars)` and forbids `GetText(-1)`; that protects latency, not completeness. Snapshot tests protect context/age, not truncation. The fix must retain both safety guarantees.

Decisive retained evidence: `proofs/source-contract.mjs`, `proofs/source-contract.log` WSW-002; source-only.

## Load/save, failures and refutations

- Catalogue: shared ordered JSON groups are read at boot; unreadable/invalid top-level catalogue warns and uses documented emergency ASCII brackets/quotes. Ingestion skips malformed entries. Empty ingestion falls back; fallback warning observability for a syntactically parsed but useless groups array is not claimed equivalent to a full catalogue.
- State: Init resets state and epoch, loads `wrap_symbols.toml` as UTF8, builds active map, and logs. Read failure latches `_WS_LoadFailed` and blocks later writes, including reset, rather than replacing an unreadable user file with empty state. Absent file allows fresh-install save. Disabled tokens serialize individually, preserving spaced guillemet key; full shared TOML string codec handles escaping.
- Transactions: global configuration write lease, bound path and monotonic state epoch reject stale candidates; no inherited Critical spans contain filesystem stages; native replace happens outside Critical, then live map publication is short. Writer/replace/authorization/publish/refused cleanup each logs. A durable-but-unpublished result explicitly requires reload and is not called silently applied. Cancel/refused commit does not rebuild a success menu.
- Legacy binding pair parser accepts catalogue opening or closing (opening wins), or exactly one `|` with nonblank sides; trims outside value, preserves internal custom delimiter spaces, rejects CR/LF in delimiter value. Multichar `**|**` and supplementary characters work at this action grammar, independently of single-character automatic custom-symbol editor.
- Both hotstring and preview buffers reset atomically after successful prefix wrap; finally releases suppress depth after throws. Preparation refusal keeps the already-delivered physical symbol intact; remapped branch attempts bare-symbol fallback. These historical fixes are present.
- Normal `SendNewResult` is SendEvent at caller level2 and IS visible to prefix hook I1; a broad hypothesis that all remap output is filtered was refuted. Successful final `SendInstant` is the separate low-level final-output path relevant to WSW-001.
- UIA worker is separate/killable, warmed after ready, deadline/backoff bounded; feature-off/pause/unsupported process avoids probes. It fences worker generation, HWND/control/input epoch, and snapshot one-time consumption/age. Pause/reload cancel selection capture and terminate workers; resume warms a successor. These guard stale/duplicate callbacks, not completeness.
- Secure/password: password query is a distinct worker request. Automatic selection request relies on the provider's TextPattern/selection behavior and contains no explicit IsPassword check; protected/unsupported providers generally return no accessible selection, with refusal/backoff. No provider-bypass or secret read was executed or claimed. User-invoked explicit selection capture uses native copy, with privacy/ignored-app policies belonging to public action admission rather than a fabricated universal clipboard filter.
