## 0. Règles & vérification (à relire avant de coder)

- **SSoT.** Zéro duplication de valeur/logique entre les 3 drivers (`windows/` AHK,
  `macos/` Hammerspoon, `linux/` LuaJIT). Le canonique vit une fois dans `_shared/`,
  lu en fail-fast. Duplication tolérée uniquement si un gate JS (valeur == canonique)
  ou un corpus partagé la verrouille.
- **§5.9.** Tout bug corrigé ET toute feature embarque un test rouge-avant/vert-après
  encodant la cause racine, dans la bonne suite.
- **Vérifier avec les VRAIES suites avant chaque commit :** `npm run build:domain`,
  `npm run test:js`, `cd static/ergopti_plus/macos && lua tests/run.lua`,
  `cd static/ergopti_plus/linux && lua tests/run.lua`.
- **Suite AHK (exécutable ici) — uniquement via Git Bash :**
  `"/c/Program Files/AutoHotkey/v2/AutoHotkey64.exe" "<abs>/static/ergopti_plus/windows/tests/run_all.ahk"`,
  résultats dans `%TEMP%\ergopti_test_results.txt` (dernière ligne `# N passed, M failed.`).
  **Ne PAS** lancer via PowerShell `Start-Process` ni rediriger stdout (`>/dev/null`) :
  l'exe GUI perd son handle stdout → `FileAppend(x,"*")` lève « invalid handle » et
  avorte tout au 6ᵉ marqueur. `#Requires v2.0` : **pas** de fat-arrow à corps `() => { … }`
  (v2.1 seulement), **pas** d'échappement v1 `""""` — le gate
  `tools/test/test-ahk-v2-syntax-antipatterns.cjs` le vérifie.
- **Fichiers AHK** = UTF-8 **BOM** + CRLF ; éditer via l'outil Edit, jamais `cat >>`.
- **Motif Lua nil-global :** un `local`/`local function` utilisé au-dessus de sa
  définition lie le global nil → crash. Forward-déclarer. Tout nouveau `.lua` doit être
  chargé **et son chemin exercé** par un test.
- **Daemon-only 🐧 :** le mainteneur est sous Windows ; le driver Linux tourne ici sous
  Lua 5.4 (unit tests), jamais sous LuaJIT/GTK/D-Bus/evdev réels. « Fait » 🐧 = codé +
  testé unitairement avec mocks, **pas** vérifié en prod. Ne pas cocher comme vérifié.
- **Commits & code :** Conventional Commits, anglais, jamais de `Co-Authored-By`. **Ne
  jamais** citer de numéro de plan (P0-G.6, P2.5…) dans un commit ou dans le source.
