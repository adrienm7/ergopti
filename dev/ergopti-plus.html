Touche magique ★

Un suffixe explicite pour les expansions longues

Pour vos snippets fréquents — formules, signatures, identifiants — la touche ★ déclenche l’expansion sans aucune ambiguïté. Aucun risque de collision avec la frappe normale.

  • ct★ → c’était
    ct★ génial → c’était génial
  • pex★ → par exemple
    pex★ ce matin → par exemple ce matin
  • pcq★ → parce que
    pcq★ il pleut → parce qu’il pleut
  • eef★ → en effet
    eef★, c’est vrai → en effet, c’est vrai

1 Répéteur de lettre

Si aucune abréviation ne correspond, ★ double simplement la lettre précédente. Plus aucun SFB sur les doublons.

  • l★ → ll elle
  • r★ → rr erreur
  • t★ → tt attendre
  • n★ → nn année

2 Déclencheur d’abréviations

Si les lettres précédentes forment un trigger connu, ★ expanse à la place. Les deux modes sont décidés au moment de la frappe — sans configuration.

  • a★ → ainsi
  • c★ → c’est
  • dé★ → déjà
  • ê★ → être
  • m★ → mais
  • pê★ → peut-être

Signature, IBAN, formules récurrentes : ajoutez vos hotstrings en un clic depuis le menu — stockés dans un simple fichier TOML, rechargés à la volée.

Hotstrings dynamiques

Certaines valeurs changent tous les jours (la date) ou ne doivent pas être écrites en dur (téléphone, IBAN). Le préfixe @ les calcule au moment précis du déclenchement, depuis l’éditeur d’informations personnelles.

  • @dt → 22/07/2026 Date du jour
  • @dtL → 22 juillet 2026 Date en lettres
  • @ph → +33 6 12 34 56 78 Téléphone configuré
  • @np★ → Moyaux ⇥ Adrien Remplissage de formulaire

Nom, e-mail, téléphone, adresse, IBAN : tout est centralisé dans une seule fenêtre — les hotstrings dynamiques s’en servent automatiquement.

3 Choisissez (ou écrivez) votre profil de prompt

○○○ Autocomplétion — Aucun prompt, juste le contexte

Aucune instruction injectée : le modèle reçoit le contexte brut et continue. Idéal pour le code et les formats stricts.

●○○ Basique — Prédiction simple

Instruction minimale : continuer le texte entre N et M mots, sans commentaire. Le compromis vitesse/qualité par défaut.

●●○ Avancé — Correction + Prédiction

Deux lignes en sortie : la fin de phrase corrigée, puis la suite prédite. Bilingue FR/EN, avec exemples intégrés pour les petits modèles.

●●● Batch Avancé — 1 req. avancée avec {n} prédiction{s} batch

Le contrat « Avancé », mais N suggestions distinctes en une seule requête — beaucoup plus économique que N appels.

L’éditeur de prompts intégré accepte vos propres instructions avec les variables {context}, {min_words}, {max_words} — imposez un ton, une langue, un métier. « Termine mes phrases comme Hemingway » est un profil valide.

36 emplacements de gestes. 3 axes continus.

L’autre moitié du gain.

Tout ce qui précède fonctionne sur n’importe quelle disposition. Les fonctionnalités ci-dessous, elles, exploitent les positions exactes des touches d’Ergopti — si vous adoptez la disposition, Ergopti+ les active automatiquement.

Roulements de bigrammes

Des séquences inconfortables remplacées par des roulements fluides sur doigts adjacents. Vous tapez ce qui est confortable, le mot correct sort.

  • sx → sk ask, task, desk
  • cx → ck back, check
  • hc → wh what, when, while
  • nt’ → n’t don’t, can’t

Réduction des SFBs

La virgule devient une super touche morte qui neutralise les derniers bigrammes à même doigt. Les touches É/È/Ê s’en chargent côté gauche.

  • ,t → pt aptement
  • éà → ié ciel
  • àé → éi antérieur
  • êe → œ sœur

Symboles de programmation

Les combinaisons pénibles du code deviennent des roulements vers l’intérieur sur la home-row d’Ergopti.

  • $= → => fat arrow
  • +? → -> Rust, types
  • !# → != différent
  • <@ → </ fermeture HTML

, + voyelle = J

Le j cède sa place à la touche ★. La séquence ,+voyelle — inexistante en français — produit le j : ,a → ja, ,e → je.

, + consonne = lettres rares

,è → z, ,y → k, ,s → q, ,c → ç. Les lettres rares restent à une frappe du repos.

Q + voyelle = QU

En français, q implique presque toujours u : tapez qe, qoi — le u s’insère tout seul.

ê = circonflexe direct

Une touche dédiée pour le cas le plus fréquent, et êa, êi, êo, êu pour â, î, ô, û.

Suffixes en à

às → ement, àt → ation, àr → eur… Les terminaisons fréquentes en deux frappes au lieu de cinq.

Apostrophe typographique

Dans du texte, ' produit ’ ; dans du code, elle reste droite. Aucun réglage.

En bonus sur Windows

  • Ergopti sans installation. Le driver peut émuler la disposition Ergopti par-dessus votre layout actuel — aucun installateur, aucun droit admin. Idéal au bureau ou sur un poste verrouillé.
  • Le meilleur d’Ergopti, même en AZERTY ou Bépo. Sans changer de disposition, profitez de la couche de symboles AltGr d’Ergopti et des chiffres en accès direct — deux des plus gros gains de la disposition, disponibles partout.
  • Spotlight curseur. Un halo met votre curseur en évidence et repère les autres écrans — parfait pour les présentations.

En bonus sur macOS

  • App Cloner. Clonez n'importe quelle application (VS Code, Slack…) : le clone reçoit sa propre icône teintée, son nom et son profil isolé. Plusieurs instances vraiment séparées, sans droits admin.
  • Encryptor. Déposez un fichier sur l'icône : il est chiffré en AES-256 (extension .enc). Redéposez-le : il est déchiffré. Aucun réglage, rien à apprendre.
  • MLX et gestes complets. Inférence IA accélérée par Apple Silicon, et le moteur de gestes intégral (36 emplacements + 3 axes continus).
