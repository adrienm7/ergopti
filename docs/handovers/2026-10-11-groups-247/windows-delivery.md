and the operating system's .NET/UIA facilities. It does not require Node,
Python, MSVC, a checkout, Ollama or a model. The shared page and native browser
fallback expose translated collection, cancellation, guided/skip and folder
controls. One retained owner survives Diagnostics close/reopen. Exact ZIP bytes
are acknowledged and verified; unexpected/control files and private synthetic
sentinels cannot enter the archive. A failed archive leaves an explicit local
error receipt and retained partial-file state.

commit and runtime file version. They cannot claim installed-binary evidence.
An installed collector requires its complete embedded source SHA. The archive's
cleanup PASS applies to the owned window and control files; the worker honestly
records its later host-tree retirement as awaiting a peer acknowledgement. The
driver publishes terminal state only after canonical task retirement.

text/modifier/visual steps require explicit guided observations; skip, cancel
and missing observations never become PASS. Hotstrings, AI, capture/replay,
callbacks, FIFO and effective-modifier providers remain explicit UNRUN where
the required exclusive native collector is not implemented. The observed
resident custody is recorded without launching another input owner. No download
or installation consent is inferred from collecting diagnostics.
