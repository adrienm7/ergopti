# Wayland desktop changes, container proof (2026-11-10)

Command: TMPDIR=/tmp bash static/ergopti_plus/linux/tests/desktop/run_wayland_sessions.sh
Base: origin/dev 1d5fe5941e. Ubuntu 24.04.5 container, root, headless, no /dev/dri.
Compositors: sway 1.9 (WLR_BACKENDS=headless), KWin 5.27.11 (kwin_wayland --virtual,
Plasma 5), GNOME Shell 46.0 (--headless --wayland --no-x11), each with its own
XDG_RUNTIME_DIR and session bus.
Path: workspace_switcher.current_workspace_source -> system_metrics.bind_desktop_source
-> observe_desktop, switches through workspace_switcher.switch (swaymsg, KWin D-Bus),
each switch at least 1.15 s from the previous read.
