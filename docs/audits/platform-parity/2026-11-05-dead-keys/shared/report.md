Audited `f2c3ea43542c985fb20e5f0887976f1c02525341`, with original Python converter and original Lua parser/converter fixtures under Lua 5.4 and LuaJIT. Genuine installed libxkbcommon processes converter-produced Compose tables. ## DKS001 — inherited Compose descendants shadow an explicit terminal

Shipped Bépo XML action `cedille`, state `monnaie`, declares **₢**. Both original converters emit `<dead_currency> <dead_cedilla> : "₢"` and report no conflicts. The generated table begins with `include "%L"`; the installed locale contains longer `<dead_currency> <dead_cedilla> <C/c>` sequences producing **₵**. On the actual native Compose state machine, feeding the two generated keysyms leaves status COMPOSING, producing no text. Following with c completes the inherited **₵** sequence instead of the explicit **₢** terminal.

`prefix_probe.py` asserts five controls. The original generated table and the locale-plus-explicit minimal table reproduce the failure. Removing the locale include, using only the explicit rule, and substituting a private first trigger complete **₢** at the second key. Ordinary currency+c remains correct in the generated table. These are isolated data controls, not proposed production patches. The installed native library and locale file are fingerprinted in `prefix.json`; behavior on other locale versions is not assumed.

Root source: Python `keylayout_to_xkb.py:725` chooses existing standard dead triggers; `:838` writes terminal output sequences; `:877` includes the locale without detecting inherited descendants. Lua `layouts/xkb_converter.lua:420`, `:561`, `:614` makes the equivalent construction. A text-level assertion that the expected rule exists does not test whether native Compose can complete it. This is a single inherited-prefix collision root, not a separate bug for each C/c descendant or converter language.

Priority medium; confidence high for the original converter/native component with the fingerprinted dependency and locale. The shared registry contract expects ₢ after this two-symbol path. The probe observes a native library, not a compositor, desktop input source or receiving application. It does not claim native macOS or AHK execution. A fix should avoid or explicitly reject overlapping inherited prefixes while preserving required locale behavior; blindly deleting the entire locale include would change other compositions. Add a native protocol regression requiring COMPOSED/₢ after exactly the pair, with inherited prefix and ordinary locale controls.

## Enumeration and intentional limits

Both final sweeps enumerate **6 layouts, 140 states and 4,391 unique reachable wire expectations**, using all seven converter levels. Original Python canonical models equal original Lua fixture dumps under both interpreters, and generated symbols/Compose hashes match for every layout. Explicit output checks use original parsed action/state relations, not an independent native macOS oracle. The enumeration covers supported registry entries and converter reachability; it does not establish every physically reachable system layout or every unspecified fallback pair.

Nine native deviations appear: one new Bépo prefix collision and eight already known magic-key deviations, four each in Ergopti Plus ISO/ANSI. Those involve the documented `base_level_only` star substitution, for which the normal action mapping remains j/ξ/ʲ/ⱼ inside pending states. They are retained in `candidate-matrix.json` as known limitations and not counted as new roots. Existing converter tests explicitly skip these magic keysym contexts. No other deviation appears among these 4,391 explicit reachable expectations; that is a qualified zero, not a universal parity guarantee. `enumeration.json` retains all measured source counts, state-entry sequences, mismatches and runtime hashes.

All **51 original Python converter tests** pass in each final sweep. They include parser, canonical form, registry conversion, chained keys, correction boundaries and corpus checks. Their success alongside DKS001 shows the gap between emitted-rule membership and native inherited-prefix semantics. Existing chained-key corrections and Linux one-shot roots are deduplicated. Linux agent separately owns the consumed-key pending-state runtime root DKL001. Windows row-off behavior is owned by the Windows agent; shared missing-state/fallback relations are source observations, not measured native macOS output.
