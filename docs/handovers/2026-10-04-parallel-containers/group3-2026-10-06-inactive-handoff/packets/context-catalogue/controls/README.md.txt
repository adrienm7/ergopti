# Private Linux contextual one-shot catalogue prerequisite

This packet prepares the catalogue and picker prerequisite for the independently
reviewed native one-shot Shift producer. It is not integrated and does not claim
physical evdev/uinput, desktop, installation, or complete TODO 93 qualification.
Caps Word remains unclaimed and unavailable.

The only new canonical claim is Linux `one_shot_shift`, restricted to
`tap_hold` and `key_combinations`. Both contexts have an actual native owner in
one-shot receipt `4efd7f0a` composed with origin/refit successor `ced31`. The
ordinary gesture executor has no one-shot handler. Its generic names, picker,
assignment and runnable permission remain false, and direct execution and generic
handler injection are refused for declared context-restricted rows only. Unknown,
computed modifier and ordinary plugin-handler semantics remain unchanged.

The generator validates only `contexts_linux`, because Linux is presently the
only driver with an implemented context consumer. It refuses empty/non-array,
unknown/non-string/duplicate contexts and contexts on an unclaimed platform.
Dormant `contexts_ahk` and `contexts_hs` remain unknown fields. It emits the native
contexts in Linux metadata. Actual generator execution in the private snapshot
leaves Windows and macOS generated bytes exact; removing only the new one-shot
row produces the exact previous Linux catalogue model and order.

A central pure shared helper implements eligibility. Linux GestureManager calls
it for the generic/contextual enumerations and execution boundaries. The actual
ordered-pair menu requests `key_combinations`, then still requires the actual
pair owner's `validate_slot` before displaying/confirming a row. Enumeration is
not native execution authority. No tap-hold manager, hook or pair producer source
is modified by this packet.
